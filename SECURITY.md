# Security

## Reporting a problem

Please report a suspected vulnerability privately through GitHub's security-advisory feature rather than opening a public issue with exploit details, credentials or personal data.

## Scope

The repository contains agent instructions and local helper scripts. It does not operate a hosted service or collect telemetry.

Several skills inspect local system state or prepare commands for external providers. Review each command and target before use. Do not include secrets in issue reports, fixtures, plans or logs.

No skill grants authority to publish, send, delete, purchase, change billing, use credentials or mutate an external system. Those actions retain the user's normal approval boundary.
