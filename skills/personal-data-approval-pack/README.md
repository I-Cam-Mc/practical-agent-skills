# Personal Data Approval Pack

A Codex skill for preparing privacy-sensitive contact, calendar, note and credential-maintenance work without silently making changes.

It turns a broad cleanup request into a read-only inventory, a small review queue, an exact mutation manifest, a backup record and a post-write verification plan. All included examples are synthetic.

## Install

Install from `skills/personal-data-approval-pack` or copy that folder into your Codex skills directory.

## Safety boundary

The skill does not grant permission to edit or delete personal data. Live mutations require explicit approval for the exact operations and destination.
