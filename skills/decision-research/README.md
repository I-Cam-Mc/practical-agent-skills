# Decision Research

A file-based Codex skill for converting policy, programme, funding, market or strategy evidence into an auditable decision brief.

The method keeps source, claim, programme and contradiction registers separate. It preserves financial status and scope, constrains causal language to the study design, and makes unresolved evidence visible.

This clean public package contains original instructions and templates. It does not vendor FS-Researcher, WebWeaver or DeepVerifier code or prompts. See [ATTRIBUTION.md](ATTRIBUTION.md).

## Install

Install from `skills/decision-research` or copy that folder into your Codex skills directory.
