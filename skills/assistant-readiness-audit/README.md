# Assistant Readiness Audit

A vendor-neutral Codex skill for checking whether a personal or company assistant is actually operational across identity, channels, routing, schedulers, permissions and end-to-end readback.

It is designed to catch the gap between green configuration screens and a verified working assistant.

## Install

Install from `skills/assistant-readiness-audit` or copy that folder into your Codex skills directory.
